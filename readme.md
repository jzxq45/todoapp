# TodoApp

TodoApp помогает вести список дел. Приложение можно открыть в браузере или
установить на Android.

## Что умеет

- Добавлять, менять и удалять задачи.
- Отмечать задачи выполненными и фильтровать список.
- Ставить дату и время выполнения.
- Напоминать о сроке задачи на Android.
- Сохранять задачи на сервере или в телефоне.

## Запуск на компьютере

Нужен Go. В корне проекта выполните:

```sh
make run
```

Откройте http://localhost:8080. Для проверки запустите `make test`.

## Запуск в Docker

```sh
docker compose up --build
```

Сайт будет доступен по адресу http://localhost:8080.

## Android

Для сборки нужен Android SDK и JDK 17:

```sh
make apk
```

Готовое приложение появится в `dist/TodoApp.apk`. Установка через ADB:

```sh
adb install -r dist/TodoApp.apk
```

## Как отправляем изменения

Перед отправкой запускаем `make test` и `make lint`, затем сохраняем изменения
коммитом и отправляем рабочую ветку в GitHub. APK и локальный путеводитель
остаются на компьютере.
